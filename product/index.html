Product overview · Phase 5+

Studio, Hub, and themes

Three surfaces in the ARC rebuild. Links below are local demo ports on the Hiker box — not production SaaS URLs. Nothing here sells a subscription or takes payment.

Studio

The photographer’s public site and manage console (Choice B: Fastify + SQLite).

  • Public — photographers, albums, services, booking request form
  • Manage — DID Connect QR (official @arcblock/did-connect-js), demo/token fallback, Hub signed apply, JPEG/PNG uploads
  • Themes — apply pack; public UI loads pack CSS + lightbox
  • Payment — booking payment frozen by default; optional beta TBA behind flag

Open Studio Manage · http://127.0.0.1:3101/

Hub

Discover and search studios; join via DID-signed apply; pull catalog from Studio public APIs.

  • Discover / search — approved studios and items
  • Join — POST /api/hub/join/apply with x-glofter-did/sig/ts; pending queue; operator approve
  • Sync — Hub pulls Studio /api/photographers & /api/albums (not legacy signed push)
  • Not included — PaymentKit join fee, NFT stake, paid theme market

Open Hub · http://127.0.0.1:3102/

Theme packs

Package @glofter/themes ships real packs — not CSS-token stubs alone.

  • Packs — minimal, magazine
  • Each pack — pack.manifest.json, tokens, layouts, lightbox chrome, pack.css bundle
  • Studio — list / apply / download ZIP from manage Themes
  • Still stub — not the legacy React theme runtime; no paid Hub theme store

Studio → Themes GET /api/themes

Identity & payments: DID Connect for manage is live (QR + poll). Customer booking PaymentKit / mainnet remain out. TBA TransferV2 only when GLOFTER_ENABLE_TBA_PAYMENT=1.
